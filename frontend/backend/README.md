# Green Fresh Backend Forwarder

If you ran `cd backend` while already inside the `frontend` folder, you can run:

```bash
npm run dev
```

This will automatically forward and start the real backend server in `c:\Users\Hp\green fresh app\backend` on `http://localhost:5000`.

Alternatively, to go directly to the actual backend folder:

```bash
cd ..\..\backend
npm run dev
```
